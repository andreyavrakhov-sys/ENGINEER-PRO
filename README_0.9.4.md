# ENGINEER PRO 0.9.4 — Windows

- Відсіювання явно екологічних/довідкових рядків зі звірки специфікації (не видаляє вихідні документи).
- Пошук кандидатів з перевіркою конфліктів потужності, IP та габаритів.
- Для запропонованого кандидата відображається кількість кошторису та розрахункова різниця за сумісних одиниць.
- Кандидати НЕ підтверджуються автоматично: потрібна інженерна перевірка.
- Оновлено версію інтерфейсу та package.json.

## Перевірити після встановлення
1. Версія v0.9.4, старі проєкти та завдання збережені.
2. Зчитати специфікацію B та звірити з Excel-кошторисом A.
3. У колонці можливих відповідників перевірити кількості та різницю (зокрема вентилятори).
4. Переконатися, що позиції екологічних викидів не потрапляють до зіставлення.
5. Експорт XLSX відкривається в Excel, п’ять аркушів на місці.
6. Перевірити, що схожі позиції з різною потужністю не позначені підтвердженими.

Увага: це попередня звірка, не автоматичний фінальний кошторис.
