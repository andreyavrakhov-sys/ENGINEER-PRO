# Виправлення помилки запуску ENGINEER PRO 1.0

Помилка: `Cannot find module './shared/sync'` із `main.js`.

У `package.json` розширено перелік файлів Electron-пакета. У `build-1.0.yml` додано перевірку присутності `shared/sync.js` усередині зібраного `app.asar`. Якщо файлу немає, Windows job завершиться помилкою, а не видасть неповний інсталятор.

1. Замініть файли репозиторію вмістом архіву, включно з прихованою папкою `.github`.
2. Запустіть **Actions → ENGINEER PRO 1.0 - EXE and APK → Run workflow**.
3. Завантажте новий EXE із **Artifacts**, установіть його поверх старої версії та перевірте запуск.
4. APK збирається окремим job; наявність APK і працездатність синхронізації потребують окремої перевірки.

Перевірено локально: синтаксис JavaScript, наявність файлів у вихідному ZIP. **Реальне збирання EXE та APK тут не виконано.**
