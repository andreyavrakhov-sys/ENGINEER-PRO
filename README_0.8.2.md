# ENGINEER PRO 0.8.2 — контроль шифрів і неоднозначних позицій

- Зіставлення за точною нормалізованою назвою, а для повторів — лише за однозначним шифром.
- Розбіжність шифру не позначається повним збігом, навіть якщо назва, одиниця і кількість збігаються.
- Відомість показує шифр A і шифр B, обидва вихідні рядки, окремі фільтри шифрів і неоднозначностей.
- Якщо кілька позицій неможливо однозначно зіставити, вони залишаються на ручну перевірку. Можливі дублікати у списку B — це не підтверджені додаткові обсяги.
- Збережено всі попередні модулі й локальні дані.

**Обмеження:** лише попереднє табличне зіставлення. Скановані креслення, специфікації PDF, характеристики, нормативна обґрунтованість, комплектність та ПНР не перевіряються автоматично. Не використовувати результат як готовий остаточний кошторис без інженерної перевірки.
