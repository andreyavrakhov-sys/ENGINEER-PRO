# ENGINEER PRO 0.9.0 — групове порівняння файлів

- У розділі «Проєкти й файли» оберіть базовий кошторис A.
- У списку B виберіть кілька файлів із Ctrl/Shift або натисніть «Вибрати всі, крім A».
- «Прочитати та зіставити» порівнює A з об’єднаними рядками B (до 3000 рядків B через обмеження рушія).
- «Зчитати специфікацію B» послідовно обробляє всі обрані PDF/XLSX/CSV; OCR працює за наявності підтримки.
- Зіставлення специфікації з кошторисом A і експорт CSV доступні після імпорту кошторису.
- Якщо файли мають однакові позиції, можливі дублікати; вони не об'єднуються автоматично.
- GitHub Actions використовує npm install, щоб уникнути старої помилки npm ci. Для стабільної збірки в майбутньому слід закомітити оновлений package-lock.json.
