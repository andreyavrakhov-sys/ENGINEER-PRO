# ENGINEER PRO 0.9.8 — єдина діагностика

1. Відкрийте Діагностика → Повна діагностика (один запуск).
2. У системному вікні виберіть **одночасно** кошторис XLSX/CSV та PDF проєкту (Ctrl для множинного вибору). Файли повинні бути в одній папці для спільного вибору; інакше зберіть копії в одну папку.
3. Програма запускає всі 10 попередніх тестів, 4 регресійні перевірки і аналіз обраних реальних файлів, звірку.
4. Натисніть Зберегти звіт JSON і надішліть його для аналізу.

Звіт не містить назв, шляхів або тексту проєктів. Результати реального зіставлення — **попередні**, не підтвердження повноти кошторису. OCR, AI, інтернет і натискання кожної кнопки не тестуються. Якщо файли не вибрано, відповідні тести SKIPPED, не PASS.
