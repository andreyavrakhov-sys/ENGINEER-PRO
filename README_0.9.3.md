# ENGINEER PRO 0.9.3 — Windows

Виправлено пошкодження XLSX: правильні ZIP general-purpose flags і compression method в local та central headers. Перевірено openpyxl.

Кнопка «Звірити з імпортованим кошторисом A» тепер автоматично імпортує обраний файл A, якщо кошторис ще не імпортовано.

Тестування: вибрати A (Excel), B (PDF), натиснути «Зчитати специфікацію B», потім «Звірити…», «Експорт звіту XLSX». Відкрити звіт в Excel, перевірити 5 аркушів та дані.

Обмеження: пошук відповідників попередній; відсутність точного збігу не доводить відсутність матеріалу. Android не змінено.
