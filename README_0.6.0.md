# ENGINEER PRO 0.6.0

Додано діаграму Ганта за задачами: початок/завершення, календарна шкала, відображення завершених робіт, експорт CSV з BOM UTF-8 для Excel. Дата початку не може бути пізнішою за завершення. Для старих задач без початку використовується дата завершення як одноденна задача. Всі попередні модулі збережені.

Обмеження: календарні, не робочі дні; немає залежностей, ресурсів і критичного шляху; графік обмежено 366 днями. Експорт CSV не є нативним XLSX.

Використання: Завдання → введіть назву, початок, завершення → Додати → Календар робіт.

Публікація: завантажити всі файли до репозиторію, Actions → Build and publish ENGINEER PRO → Run workflow → 0.6.0.

Тестування: перевірка синтаксису JavaScript та архіву; Windows EXE не збирався локально.
