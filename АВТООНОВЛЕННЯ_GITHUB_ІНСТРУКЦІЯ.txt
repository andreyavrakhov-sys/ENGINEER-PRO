ENGINEER PRO 0.2.2 — GitHub Releases автооновлення

Репозиторій: https://github.com/andreyavrakhov-sys/ENGINEER-PRO

1. Розпакуйте цей архів до нової папки ENGINEER_PRO_2.
2. У CMD з активним Node.js виконайте npm ci, потім npm run dist.
3. У папці dist будуть ENGINEER_PRO_Setup_0.2.2.exe, latest.yml та .blockmap.
4. На GitHub відкрийте Releases > Draft a new release. Створіть тег v0.2.2, оберіть Latest release, НЕ позначайте prerelease, додайте ці три файли та опублікуйте.
5. Після публікації встановіть ENGINEER_PRO_Setup_0.2.2.exe. Встановлюйте поверх попередньої версії.
6. Для перевірки автооновлення потрібно опублікувати ВИЩУ версію (наприклад 0.2.3) з аналогічними файлами. Програма перевірить GitHub приблизно через 12 секунд після запуску, автоматично завантажить нову версію та запропонує перезапуск.

ВАЖЛИВО:
- Не завантажуйте на GitHub файли з API-ключами або secrets.json.
- Автооновлення працює лише у встановленій/зібраній програмі, не при npm start.
- Цей ZIP — вихідний проєкт, а не готовий інсталятор. Windows-збірку необхідно виконати на вашому комп'ютері.
- Підписування сертифікатом видавця не налаштоване; Windows SmartScreen може показувати попередження.
- Автоматичне завантаження налаштоване, встановлення після підтвердження у програмі або виходу з неї (стандартна поведінка electron-updater).
