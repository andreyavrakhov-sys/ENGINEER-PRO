# ENGINEER PRO 0.3.4

Новий розділ **Програми та папки**: вибір встановлених `.exe`, вибір робочих папок, відкриття натисканням, видалення ярликів. Ярлики зберігаються локально у `launchers.json` у userData. Програми запускаються без командного рядка, без аргументів, у власній робочій папці. Для безпеки запуск лише обраних користувачем EXE; папки відкриваються через Windows Explorer. Виправлено пошкоджену HTML-розмітку кнопки порівняння у версії 0.3.3.

Windows EXE збірку ще не тестовано. Після завантаження вихідних файлів у GitHub запустіть workflow із версією `0.3.4`.
