# ENGINEER PRO 0.9.13 — Document Quality & Candidate Review

## Зміни
- Визначення типу документа за шифром розділу в назві PDF, з пріоритетом над загальними словами всередині документа. ПОБ більше не класифікується як РЗА.
- ПОБ, пояснювальні та екологічні документи не додають автоматично виділені текстові рядки до переліку специфікацій. Це консервативний фільтр; відомості з цих документів можуть потребувати окремого ручного аналізу.
- Відсіювання точних дублікатів позицій у межах однієї сторінки; однакові позиції на різних сторінках залишаються.
- Новий статус «Високовірогідний збіг — перевірити за оригіналом»: єдиний кандидат зі схожістю >=0.78, однаковою кількістю, сумісними одиницями, відсутніми технічними конфліктами та збереженими числовими характеристиками. Це НЕ підтверджений збіг.
- JSON-діагностика включає кількість високовірогідних кандидатів та пояснення статусу. Чотири нові інтегровані еталонні перевірки й окремий тестовий набір `test-quality-0913.js`.

## Обмеження
- Не реалізовано повне відновлення багаторядкових назв у складних PDF.
- Відсікання ПОБ не доводить, що його відомості непотрібні для кошторису; машини, трудомісткість і ресурси ПОБ перевіряються окремо.
- Дублікати на різних сторінках не об'єднуються, бо можуть бути реальними повтореннями.
- Статус «Високовірогідний» потребує перевірки креслення та марки; жодне порогове значення схожості не доводить правильності кошторису.

## Перевірки
`npm test` — всі 10 наборів пройдено. `node --check main.js` та `node --check specification-analyzer.js` — пройдено. Windows-інсталятор збирається окремо в GitHub Actions.
