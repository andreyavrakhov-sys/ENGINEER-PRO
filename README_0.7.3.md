# ENGINEER PRO 0.7.3 — щоденна робота

- У блоці «Сьогодні» задачі можна позначити виконаними одним кліком, зі збереженням у наявному сховищі.
- Позначення прострочених задач, індикатор прогресу й високого пріоритету.
- Нотатки зберігаються автоматично після 650 мс без введення; показується статус.
- Ctrl+N — нова задача; Ctrl+1…8 — основні розділи; Ctrl+K — глобальний пошук.
- Правильне визначення поточної дати за локальним часом Windows.
- Пошук файлів має повідомлення, якщо збігів немає; повний шлях видно при наведенні.
- Покращена клавіатурна доступність плиток і контраст активних рядків.
- Усі інші модулі, банер, дані та оновлення збережено.

Для релізу: замінити вміст репозиторію та запустити GitHub Actions з версією 0.7.3.
