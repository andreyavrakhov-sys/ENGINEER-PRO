# ENGINEER PRO 0.9.5 — коректне відображення кошторису

- Нижня таблиця «Прочитати та зіставити» тепер використовує структурований імпортер АВК-5: назва — колонка C, шифр — B, одиниця — D, кількість — E.
- Усі позиції кошторису зберігають номер локального кошторису, розділ, аркуш і рядок.
- Прибрано помилкове твердження «Відсутня B» для позицій, які не можуть бути перевірені прямим порівнянням із PDF.
- Виправлено невідповідність кількості заголовків CSV і полів.
- Окремий модуль «Специфікація проєкту → перевірка кошторису» збережено без змін.

## Контроль
1. Запустити 0.9.5, перевірити старі проєкти.
2. Обрати кошторис 1963...xlsx і PDF, натиснути «Прочитати та зіставити»: має бути 435 позицій із повними найменуваннями, а не лише шифрами.
3. Перевірити першу позицію: «Розроблення грунту з навантаженням...»; шифр КБ1-18-5; кількість 0.032; одиниця 1000 м3 ґрунту.
4. Переконатися, що нижня таблиця не стверджує «Відсутня В».
5. Експортувати CSV, перевірити 16 колонок і їх відповідність значенням.
6. Окремо перевірити «Зчитати специфікацію В» і «Звірити ... A».

Програма не доводить відсутність робіт у проєкті лише на основі текстового порівняння.
