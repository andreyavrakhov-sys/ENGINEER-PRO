# ENGINEER PRO 0.8.4 — PDF.js + optional OCR

## Що додано
- PDF.js (`pdfjs-dist`) для вилучення текстового шару з координатами: підтримка кирилиці та більшості стандартних PDF-шрифтів.
- Складання рядків за координатами Y/X, збереження номера сторінки й вихідного тексту.
- **Необов'язковий** OCR (`tesseract.js`, `@napi-rs/canvas`) для сторінок без текстового шару; мови `ukr+eng`.
- OCR обмежено 12 сторінками; читання PDF — 150 сторінками, розмір файлу — 25 МБ.
- У відомості додано «Метод читання» (`pdfjs-text` або `ocr-ukr-eng`).
- Перевірка одиниць і кількостей залишається консервативною: лише повні рядки з назвою, одиницею та кількістю.

## Залежності та збірка
В `package.json` додано `pdfjs-dist@3.11.174`, `tesseract.js@5.1.1`, `@napi-rs/canvas@0.1.80`. Через відсутність доступу до npm у середовищі підготовки повний lockfile неможливо було перегенерувати тут. У GitHub Actions додано крок `npm install --package-lock-only --ignore-scripts` перед `npm ci`, який перегенерує lockfile на Windows із доступом до npm. Під час збірки потрібне завантаження залежностей; OCR мовні дані можуть додатково завантажуватися під час першого використання.

## Обмеження
- Таблиці PDF відновлюються евристично за координатами, складні багаторядкові специфікації можуть не розпізнаватися.
- OCR не гарантує точності; відсутність збігу не доводить відсутності матеріалу в кошторисі.
- Для PDF із паролем, пошкоджених або нестандартних PDF можливі помилки.
- Режим OCR запускається тільки за вибором користувача, дані надсилаються лише до механізму завантаження мовних моделей, якщо вони відсутні локально; документи обробляються локально.
- Пакети PDF.js, Tesseract і нативний Canvas не були встановлені й не пройшли інтеграційний тест у цьому середовищі. Перед використанням перевірте Windows-збірку та реальний PDF.
