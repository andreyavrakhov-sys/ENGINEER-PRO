# ENGINEER PRO 0.9.6 — технічні обмеження та прозорі кандидати

- Відсіювання кандидатів з явно різними напругами (кВ/В), потужностями (кВт/Вт), струмами (А), IP і розмірами.
- Конфлікт технічних параметрів не стає автоматично підтвердженим збігом.
- Окремі поля найкращого кандидата, його кількості, одиниці та попередньої різниці в інтерфейсі, CSV та XLSX.
- Попередня різниця не є доказом нестачі до підтвердження відповідника.
- Результати кошторисних робіт не оголошуються зайвими тільки тому, що їх немає у специфікації.
- Android не змінено. Для Windows запустити GitHub Actions Windows release з версією 0.9.6.

Обмеження: парсинг PDF/OCR, неоднозначні найменування, складні характеристики і неповні специфікації потребують перевірки за оригіналами.
