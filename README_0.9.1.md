# ENGINEER PRO 0.9.1 — Windows

Основа: 0.9.0 MULTI FILE SOURCE. Android не змінювався.

## Зміни
- Зіставлення специфікацій з кількох PDF/XLSX/CSV із кошторисом Excel.
- Збереження вихідного файлу, сторінки, аркуша, рядка специфікації та аркуша/рядка кошторису.
- Показ усіх позицій кошторису без підтвердженого зіставлення (не оголошуються зайвими).
- Неоднозначні дублікати назв залишаються на ручну перевірку, окрім унікального збігу шифру.
- Перевірка кількості з перерахунком підтримуваних одиниць.
- CSV-експорт розширено аркушем кошторису.

## Обмеження
Це попередній текстовий аналіз, а не автоматично завершений кошторис. PDF з кресленнями/сканами може бути прочитаний не повністю; відсутність текстового збігу не доводить відсутності матеріалу. XLSX-фінальний кошторис ще не реалізовано.
