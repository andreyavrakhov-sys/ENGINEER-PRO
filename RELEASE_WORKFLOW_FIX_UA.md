# Виправлення повторного релізу

`windows-release.yml` тепер перевіряє наявність релізу. Якщо тег v1.0.0 вже існує, він завантажує нові EXE, blockmap та latest.yml з `--clobber` замість аварійної зупинки. Якщо релізу немає — створює його.

**Увага:** повторна публікація тієї самої версії замінює файли релізу, що може вплинути на кешування та оновлення. Для публічних випусків краще збільшувати версію (1.0.1 тощо).

Workflow `build-1.0.yml` створює окремі artifacts EXE та APK без публікації релізу. Реальне збирання не перевірено.
