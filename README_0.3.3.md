# ENGINEER PRO 0.3.3 — імпорт реальних кошторисів

Додано кнопку «Імпорт кошторису АВК-5 (Excel)» у блоці аналізу документів. Оберіть файл Excel у полі A.

Імпортер розпізнає номер локального кошторису, розділ, номер позиції, шифр, коефіцієнти, назву, одиницю, кількість, ціну та загальну вартість. Другі рядки друкованих позицій без кількості пропускаються. Обробляються всі аркуші XLSX (до 20000 рядків на аркуш). Дані залишаються на комп’ютері.

Перевірено на наданому «2593 Альбом локальних кошторисів.xlsx». Класифікація за префіксом шифру **попередня**, не нормативна. Нормативні PDF не включені до дистрибутива і автоматичної перевірки повного складу норм наразі немає. Скановані PDF не аналізуються надійно.

Збірка: GitHub Actions → Build and publish ENGINEER PRO → Run workflow → 0.3.3.
