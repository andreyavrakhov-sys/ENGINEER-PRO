# ENGINEER PRO 0.9.10 — PDF classification and regression checks

- Додано попередню класифікацію PDF за текстовими маркерами: specification, environment, relay-protection, explanatory, unknown.
- Парсер текстових рядків підтримує нумеровані позиції (наприклад `1 Кабель ВВГнг 4х120 м 250`), зберігає сторінку/рядок.
- Відсіювання відомих екологічних рядків, зокрема `Окис хрому` та `Газоподібні фтористі сполуки`.
- Діагностика одним запуском: 2 додаткові еталонні тести; у деталях PDF зазначається тип документа.
- Обмеження: розпізнавання багатоколонкових/багаторядкових таблиць не гарантоване; OCR залишається вимкненим у діагностиці. Відсутність позицій або збігів не доводить відсутності в проєкті. Класифікація евристична.

Перевірено `npm test`, `node --check main.js`, `node --check specification-analyzer.js`. EXE не зібрано в цьому середовищі.
