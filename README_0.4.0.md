# ENGINEER PRO 0.4.0 — робочий центр інженера

## Реалізовано
- Новий графітово-бурштиновий дизайн із адаптивною навігацією та головною панеллю.
- Головний екран: кількість задач, файлів, ярликів, виконаних задач, найближчі завдання, останні файли, швидкий запуск встановлених програм і папок.
- Завдання: дата виконання, пріоритет, завершення, видалення; дані зберігаються локально.
- Календар робіт: перелік задач за строками.
- Програми та папки: плитки, запуск Windows EXE, відкриття папок, видалення ярликів.
- Нормативні документи: локальна колекція PDF із можливістю відкриття.
- Збережено AI HUB, електрокалькулятор, кошторисний імпорт, зіставлення документів, оновлення та налаштування.

## Межі реалізації
Це функціональний інтерфейс, але **не** повний аналог AutoCAD/Excel/АВК-5: сторонні програми запускаються тільки якщо встановлені. Календар — список строків, без діаграми Ганта. Нормативні PDF відкриваються як файли, але їхній склад норм автоматично не верифікується. Імпортер кошторисів і порівняння мають попередній характер.

## Встановлення
Завантажити вміст ZIP у GitHub репозиторій зі збереженням `.github`, запустити Actions → Build and publish ENGINEER PRO з версією `0.4.0`. API-ключі не додавайте до GitHub.

## Тестування
Перевірено синтаксис JS і цілісність архіву. Повна Windows Electron/NSIS збірка та тест UI на Windows не виконувалися.
