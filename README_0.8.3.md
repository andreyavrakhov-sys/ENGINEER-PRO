# ENGINEER PRO 0.8.3 — PDF Specification Analyzer (experimental)

## Додано
- Окремий блок «Специфікація проєкту → перевірка кошторису» у «Проєкти й файли».
- Вибір PDF/XLSX/CSV зі списку B та імпорт кошторису АВК-5 XLSX зі списку A.
- Консервативне розпізнавання позицій: назва, одиниця й кількість мають бути в одному рядку.
- Для простих PDF: витяг тексту зі стандартних потоків FlateDecode та ASCII85Decode, спроба визначити номер сторінки.
- Зіставлення лише за точно нормалізованою назвою. Неоднозначні позиції позначаються, а не зіставляються довільно.
- Відомість: кількість за проєктом і кошторисом, одиниці, різниця після перерахунку сумісних одиниць, статус, сторінка/рядок, шифр кошторису, вихідний текст.
- CSV для Excel (UTF-8 BOM, захист від формул у CSV).

## Важливі обмеження
- **Це експериментальне читання PDF, не повноцінний PDF-парсер і не OCR.** Для сканів, кириличних CID-шрифтів, частини таблиць, графічних специфікацій та PDF з об’єктними потоками позиції можуть не витягуватися.
- Для XLSX/CSV потрібні сусідні колонки «найменування / одиниця / кількість». Складні шапки, об’єднані комірки та інші формати можуть не розпізнатися.
- Відсутність текстового збігу **не доводить**, що матеріал відсутній у кошторисі; інші назви, марки, комплекти, розділи та дублікати потребують ручної звірки.
- Відомість не включає автоматичний підбір норм, ПНР, додаткових робіт чи інженерних обсягів із графіки креслень.
- Не використовувати як фінальний кошторис без інженерної перевірки.

## Перевірка
`node test-specification.js` — модульні перевірки; синтаксис JS перевіряється через `node --check`. Windows EXE не збирався.
