# ENGINEER PRO 0.8.1 — Відомість розбіжностей

- Фільтр результатів зіставлення: усі, на перевірку, відсутні, додаткові, розбіжності кількості, повні збіги.
- Пошук за назвою, шифром, статусом та вихідними рядками.
- Підсвічування рядків, які потребують перевірки, лічильник результатів.
- Експорт відфільтрованої відомості розбіжностей у CSV для Excel.
- Експорт **усіх** розпізнаних позицій імпорту кошторису АВК-5, без обмеження 300 рядками екранного перегляду.
- CSV захищено від інтерпретації клітинок як формул під час відкриття в Excel.
- Збережено проєкти, задачі, календар, AI HUB, калькулятор та інші модулі.

**Обмеження:** зіставлення попереднє, за нормалізованими назвами. Не виконує повноцінного читання креслень, перевірки специфікацій чи автоматичного підбору норм. Підтвердження обсягів, шифрів та комплектності — відповідальність інженера.
