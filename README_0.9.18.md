# ENGINEER PRO 0.9.18 — Section Boundary Guard

На основі реального JSON 0.9.17: у PDF ЕМ стор. 26 вентилятор WOKS Ø400, 4 шт., був зчитаний разом із заголовком наступного розділу `2. Кабельні вироби`.

Зміни:
- Новий `table-boundaries.js` видаляє **лише відомі заголовки розділів у кінці назви**. Кількість, одиниця виміру, марка і вихідний текст залишаються незмінними.
- Вихідна назва зберігається у `originalName`; вилучений заголовок — у `sectionHeadingRemoved`.
- Діагностика додає повідомлення про кількість очищених назв.
- Додано регресійний тест, оновлено версію та lockfile.

Обмеження: не реалізовано повне геометричне відновлення таблиць. 21 PDF-позиція, 17 карантинних та 0 підтверджених збігів — базові показники **попередньої** версії, а не результат запуску 0.9.18. Windows EXE і реальні PDF не перевірялися в цьому середовищі.
