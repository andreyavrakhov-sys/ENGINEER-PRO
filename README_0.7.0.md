# ENGINEER PRO 0.7.0 — оновлення інтерфейсу

Повністю перебудована головна панель за узгодженим темно-синім/бурштиновим макетом:
- Двоколонкове робоче поле, фотографічний банер із вежею ЛЕП, чотири кольорові показники.
- Шість плиток швидких дій, останні папки проєктів і файли, плитки встановлених програм.
- Права панель: актуальні завдання, інтерактивний календар із позначенням днів зі строками, нотатки, AI HUB.
- Усі попередні сторінки та їхня логіка збережені: AI, кошториси, калькулятор, програми, папки, нормативи, календар і Гант.
- Збереження даних у попередньому форматі. Наявні задачі, файли, нотатки та ярлики не скидаються.

Банер завантажується з локального `sunset-tower.png` і включається до Windows-збірки. Скріншот макета містить прикладові числа й записи; у програмі відображаються справжні локальні дані.

## Публікація
Розпакуйте ZIP, завантажте вміст папки до кореня репозиторію, перевірте `.github/workflows/windows-release.yml`, запустіть GitHub Actions з версією `0.7.0`. Windows EXE у цьому середовищі не збирався. Перевірено синтаксис JavaScript.
