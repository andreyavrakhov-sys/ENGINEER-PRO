# ENGINEER PRO 0.3.2 — попередня класифікація позицій

- До результатів звірки додано **попередню** класифікацію «Робота», «Матеріал / обладнання», «Тип не визначено».
- Відображається попередження, що шифри норм і відповідність позицій необхідно перевірити за вихідними документами.
- У CSV додано тип позиції, стан перевірки шифру і примітку.
- Автоматичне оновлення та AI HUB не змінювалися.

**Важливо:** класифікація евристична і не є нормативним дешифратором АВК-5. Не створює нові обсяги, норми чи ціни без підтвердження. Порівняння базується на точній нормалізованій назві; різні формулювання можуть не зіставитися.
