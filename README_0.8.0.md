# ENGINEER PRO 0.8.0 — Проєкти та графіки

- Реєстр проєктів: назва, статус, перейменування, видалення без втрати задач.
- Прив’язка нових завдань до проєктів. Старі дані зберігаються.
- Фільтр діаграми Ганта за проєктом, швидкий перехід із реєстру.
- Календарні та робочі дні за кожною роботою (понеділок–п’ятниця).
- CSV-експорт графіка для Excel із назвою проєкту, строками, тривалістю, пріоритетом і статусом.
- Збережено інші модулі та оформлення.

Обмеження: не враховано свята, змінність, ресурси, залежності та критичний шлях. Сума днів по роботах не є тривалістю проєкту. Автоматична звірка кошторисів — попередня, потребує перевірки інженером.

GitHub Actions: версія 0.8.0. Збірка Windows EXE не тестувалася.
