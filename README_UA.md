# ENGINEER PRO 0.7.0

Десктопна програма для інженерних проєктів. Головний екран оновлено відповідно до наданого макета: темно-синя палітра, бурштинові акценти, компактна бічна панель, фотографічний банер, показники, швидкі дії, проєкти, файли, календар і AI HUB. Дані та основні функції попередньої версії збережені.

## Запуск із вихідного коду

Потрібен Node.js 24.

```bash
npm ci
npm start
```

Для Windows-збірки інсталятора NSIS:

```bash
npm run dist
```

Готовий інсталятор з’явиться у `dist/`. ZIP містить вихідний код, а не готовий EXE.

## Дані та можливості

- Завдання, нотатки, проєкти й ярлики програм зберігаються локально у папці даних Electron.
- AI-провайдери, додавання ключів, локальна Ollama, перегляд та порівняння документів працюють через наявні функції програми.
- Банер використовує локальне зображення `sunset-tower.png`, включене до збірки.
- Зіставлення кошторисів є попереднім: воно не замінює інженерну перевірку та не підтверджує відповідність нормам.
