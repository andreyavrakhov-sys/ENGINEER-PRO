# ENGINEER PRO 2.0 — MVP 0.1

Початкова **настільна програма** для Windows 10 x64. Це вихідний проєкт Electron, а не готовий EXE.

## Встановлення на Windows

1. Встановіть Node.js LTS з офіційного nodejs.org.
2. Розпакуйте архів, відкрийте PowerShell у папці `ENGINEER_PRO_2`.
3. Виконайте `npm install` (завантажує Electron та залежності з npm).
4. Виконайте `npm start` для запуску програми.
5. Для створення Windows-інсталятора виконайте `npm run dist` **на Windows**. Результат шукати в папці `dist`.

Не запускайте програму від адміністратора без необхідності. Потрібен доступ до інтернету для встановлення залежностей та хмарного AI. Для локального AI встановіть Ollama окремо, завантажте модель (`ollama pull llama3.2`) та переконайтеся, що сервер Ollama працює.

## Реалізовано

- Інтерфейс у графітово-помаранчевому стилі; годинник.
- ОЗП, модель CPU, число логічних процесорів, uptime (це **не** живий % CPU/GPU).
- Завдання й нотатки з локальним збереженням.
- Додавання шляхів до файлів, відкриття через Windows.
- Розрахунок трифазної/однофазної активної потужності та довжини кабелю за масою.
- AI-запити до OpenAI, Gemini, Anthropic, Ollama через backend Electron.
- Шифрування API-ключів через Electron safeStorage, якщо доступне.

## Не реалізовано

- Готовий EXE у цьому архіві, автозапуск, Desktop Overlay, Rainmeter, повноцінна тема оболонки Windows.
- Автономні AI-агенти, multi-AI, пам'ять діалогів, робота з вкладеннями AI.
- Парсинг PDF/XLSX/DWG, автоматичне порівняння кошторисів.
- Живі температури, GPU, диски, погода, новини, календарні інтеграції.
- Автоматичний вибір моделей, визначення списку доступних моделей.

## Безпека та обмеження

Ключі шифруються локально, але застосунок не проходив незалежний аудит. Не використовуйте для секретних матеріалів без перевірки політик відповідного AI-провайдера. Усі запити хмарним моделям надсилаються через інтернет. Локальні нотатки й перелік файлів не надсилаються автоматично. Кнопка «Очистити діалог» очищує лише поточну сесію; історія не записується. Вказані моделі в інтерфейсі — редаговані приклади, їхня доступність залежить від API та акаунта.

**Тестування:** синтаксис JS можна перевірити через `node --check main.js` і `node --check preload.js`. Запуск графічної програми на Windows та збірку інсталятора потрібно перевірити на реальному Windows-ПК.
