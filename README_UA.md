# ENGINEER PRO 0.2.9 — документи й звірка

Новий розділ **Проєкти та файли → Аналіз документів**. Додайте два файли, оберіть їх і натисніть «Прочитати та зіставити». Експорт CSV містить усі знайдені текстові позиції.

Підтримано XLSX (до 5 аркушів і 2500 рядків), CSV, TXT, MD та часткове витягування простого PDF-тексту. Скани, креслення, багато PDF із кирилицею та складні таблиці НЕ підтримуються належним чином. Формули XLSX не обчислюються. Зіставлення відбувається лише за точним нормалізованим текстом, без семантичної відповідності, розрахунку обсягів чи підтвердження норм. Це не готова перевірка ПКД.

## GitHub
Завантажте весь вміст ZIP у корінь репозиторію зі збереженням `.github/workflows/windows-release.yml`. Запустіть Actions → Build and publish ENGINEER PRO → Run workflow, введіть `0.2.9`. Після успішного випуску EXE з’явиться в Releases. Не публікуйте API-ключі.

## Перевірка
JavaScript синтаксично перевірений. Реальна Windows-збірка, PDF-файли різних виробників та оновлення не тестувалися.
