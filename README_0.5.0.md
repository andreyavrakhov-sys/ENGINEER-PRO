# ENGINEER PRO 0.5.0

Оновлено головний екран: прибрано дубльований блок завдань, упорядковано системні віджети. Додано глобальний пошук Ctrl+K за задачами, файлами й ярликами; фільтрацію, сортування, редагування задач; підсвічування прострочених і пріоритетних; пошук у файлах і ярликах. Збережено попередні інструменти й виправлений GitHub Actions workflow.

**Збірка:** завантажити всі файли та приховану `.github` до репозиторію; Actions → Build and publish ENGINEER PRO → Run workflow → 0.5.0. Для автоновлення необхідно опублікувати GitHub Release. Не завантажуйте API-ключі.

**Перевірки:** синтаксис JavaScript, версії package/lockfile, цілісність ZIP. Повна збірка Electron на Windows і наскрізне тестування UI не проводилися.
