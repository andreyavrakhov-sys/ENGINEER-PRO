# ENGINEER PRO 0.3.1

Виправлено інтеграцію: кнопка «Прочитати та зіставити» тепер викликає compare-engine.js через Electron IPC. CSV містить кількості, одиниці, розбіжності, номери рядків та оригінальний вміст рядків.

**Обмеження:** зіставлення лише за нормалізованою назвою, без доведеного семантичного збігу. Дані з PDF можуть бути неповними. Не вважайте результат готовим кошторисом без перевірки.

## Збірка
Завантажте в GitHub усі файли, зберігаючи `.github/workflows/windows-release.yml`; запустіть Actions → Build and publish ENGINEER PRO → Run workflow з версією `0.3.1`. Не додавайте API-ключі до репозиторію.
